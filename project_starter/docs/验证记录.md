# 模板 1.0 验证记录

验证对象为默认 bench / CT107D LED 示例，不代表所有后续项目都已通过验证。

## 已完成

- Python 自动化 25 项通过：登录与 CSRF、参数和协议检查、设备状态过期、仅有网关 ACK 不视为执行成功、回执超时与迟到回执、同设备串行控制、预约取消/错过/失败/数量限制、服务重启不重放、方案及标题持久保存、AI 候选方案与非法操作拦截、创建工程不覆盖和凭据隔离。
- 实际 firmware/main.c 命令解析与 logic.c 由宿主 C 编译器编译并执行测试；覆盖重复命令、ID 冲突、范围限制、本地计时和接收溢出恢复。
- Keil C51 在 11.0592 MHz 和 12 MHz 配置下均编译通过，无警告、无错误。程序 code 2505 字节、data 67.3、xdata 424。
- 浏览器模拟全流程：登录、设备命令/单片机模拟回执、方案、GMT+8 预约与取消、记录、网站标题、AI 消息布局。五个页面分别检查 1440/768/390 三种宽度，无整页横向溢出。
- 部署安装器 dry-run、配置生成与不覆盖测试通过；发布流水线另检查 Linux 自动化与 Bash 语法。

## 尚未验证

- 本次新模板没有烧录用户现有 ESP 或单片机，没有替换线上洗衣机/通用网关服务。
- HEX 已编译，真实 CT107D 引脚、灯光、UART 时序和电平仍须按实机验收文档核查。
- AI 使用受控模拟接口进行测试，未调用用户付费模型。真实服务的模型名、兼容路径和额度须单独验证。
- 安装器未在用户生产服务器实际安装本模板；真实域名证书、服务器环境和外部可达性仍须部署后验证。

## 页面复核

沿用通用网关的 Framed sheet 风格（seed 329921370），系统中文字体避免离线环境依赖字体下载。主要识别元素是三段通信状态和单片机执行回执。

控制台回答“设备是否可控、上次操作结果是什么”；预约回答“什么时间执行什么”；记录展示历史证据；AI 先提议再确认；设置集中管理标题、账号和 API。

实测数据来自明确标注的模拟网关，零值显示为零。数字和日期表格右对齐，聊天用户消息靠右、助手靠左。手机布局改为单列，会话列表横向选择；保留可见中文导航，便于找到功能。无图表、不添加虚构趋势或统计数字。
