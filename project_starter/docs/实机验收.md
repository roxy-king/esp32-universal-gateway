# 实机验收（不以模拟测试代替）

1. 备份旧单片机固件和 ESP 配置。示例烧入单片机后会替换原业务，先明确目标板。
2. 使用 firmware/prebuilt 中与 STC-ISP 运行频率一致的 HEX；编译自定义项目时重新生成 HEX，不能继续用 LED 示例 HEX。
3. 断电接线：CT107D P3.7 → 电平转换 HV1/LV1 → ESP GPIO18；ESP GPIO17 → LV2/HV2 → CT107D P3.6。HV接CT107D 5V，LV接ESP 3V3，两板及转换器共地。确认转换器适合当前速率；GPIO不能直接接5V。
4. ESP 保持 Gateway v1，UART9600/8N1、line、CRLF。先保持远程写入关闭。填本项目域名和独立设备令牌，ID不必相同。
5. 网页应显示 ESP在线、“本项目数据有效”，固件版本、串口参数正确，运行秒数增长。
6. 若仅显示ESP在线，先检查单片机上报帧是否是本项目P1；旧洗衣机STATUS不能通过本模板验收。
7. 开启 ESP 远程写入。网页打开 LED，确认板上 L1 亮，并且网页显示“执行成功 / 单片机回执”，不是只有发送队列提示。
8. 限时点亮3秒，确认倒计时和熄灭；单片机本地计时不依赖网页持续打开。
9. 设置 GMT+8 一分钟后的预约，确认仅执行一次；取消另一预约，确认不执行。
10. 切断ESP网络、关闭网页、重启服务器，分别检查结果。未知操作不自动重发，错过预约不补发。
11. 重启单片机，确认默认LED关闭。真实水泵、门锁等项目必须另行验收上电状态、故障保护与断网策略。
12. 配置自己的AI API后，先询问状态，再提出限时点亮建议；不点确认时设备不得动作，确认后核对单片机回复。

逐项记录日期、固件HEX哈希、实际结果和异常，不把“服务已启动”写成“设备已验证”。
