# 面板设计与检验
风格：taste-skill Framed sheet，seed 329921370。
问题：网关连接到了哪一步，如何更改连接配置？
产品元素：Wi-Fi → 云端 → UART 三段真实状态。所有缺失数据呈现为“等待读取”或“尚无数据”，不捏造在线状态。
数据与操作：项目ID、SSID、主机、端口、WSS路径、令牌、CA、串口GPIO、串口格式、帧边界、只读开关、日志、配置迁移与恢复。
离线硬件面板不加载在线字体与第三方资源，使用系统中文字体；此处有意替换样式表推荐的外部字体。
布局：1200px 上限、左右28px、两栏按1:2分配，中间28px；手机单栏。设置/诊断/维护三个可见标签，无悬浮遮挡操作。
mock仅用于测试，位于tests/preview.py；不嵌入固件，不会展示为实物读数。

复查结果：真实浏览器1440/768/390宽度检查0 FAIL、0 WARN，明确允许font-not-dealt以保障设备热点断网时可读。三种宽度截图已检查，移除了空状态提示占据的大段留白。主面板无横向溢出，设置/诊断/维护标签可切换，字段保持完整标签。云端模拟收发回包与诚实的“尚未确认执行”提示已交互验证。
