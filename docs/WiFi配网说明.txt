Wi-Fi 配网更新：UniversalGateway 1.1.0
1. 长按 ESP32 BOOT 3 秒开启配置热点。
2. 手机连接 Gateway-Setup 热点，保持连接（即使提示无法上网）。
3. 浏览器打开 http://192.168.4.1，进入 Wi-Fi 配网。
4. 扫描并选择 2.4 GHz 网络，输入密码，点击连接 Wi-Fi。
5. 页面显示已连接及 IP 后，再配置服务器；Wi-Fi 联网不等于云端已连接。
Wi-Fi 可以单独保存，不要求服务器地址和设备令牌。隐藏网络可手动输入名称。
本次更新仅写入应用区，保留原 NVS 配置与热点密码。
验证：固件编译通过；浏览器模拟扫描、选网、独立连接通过；1440/768/390 宽度无横向溢出。实际路由器连接需要用户在页面输入密码后验证。
