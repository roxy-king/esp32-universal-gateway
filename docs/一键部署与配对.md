# 一键部署向导

仓库：`roxy-king/esp32-universal-gateway`（公开，无需GitHub账号）。

## 服务器终端一行安装

以root登录Debian/Ubuntu，域名已解析到服务器、80/443端口已放行后，复制：
```bash
bash -c 'f=$(mktemp) && curl -fsSL https://raw.githubusercontent.com/roxy-king/esp32-universal-gateway/v1.3.0/install.sh -o "$f" && bash "$f"; r=$?; test -z "$f" || rm -f -- "$f"; exit "$r"'
```
下载失败时不会执行残缺文件；临时入口文件运行结束后删除，保留真实退出状态。安装入口下载固定v1.3.0源码，下载目录也会在退出时清理。若系统没有curl，先运行 `apt-get update && apt-get install -y curl ca-certificates`。
按向导输入域名、账号密码、邮箱，输入INSTALL。安装完成后，把 `/etc/esp-gateway/pairing.json` 安全下载到电脑的 `private/pairing.json`，再运行connect.cmd配对ESP。

## 推荐：Windows电脑一键向导

1. 从仓库 **Releases** 下载完整压缩包，解压到 `D:\ESP32Gateway`。不要在压缩包中直接运行。
2. 确认ESP已刷入通用网关固件。未烧录则先运行 `flash.cmd`。
3. 为服务器配置一个独立子域名A记录，开放80/443端口。不要使用原洗衣机已占用的同一域名；例如可以另外使用 `gateway.你的域名`。
4. 电脑需Python3.11+、Windows OpenSSH客户端和tar。已有原项目Python可继续使用。SSH账号为root，非默认端口用 `powershell -ExecutionPolicy Bypass -File deploy\setup.ps1 -Port 你的端口`。
5. 双击 **setup.cmd**，输入服务器IP；SSH首次连接会要求确认主机指纹，然后输入服务器密码（由ssh处理，不保存在脚本）。
6. 服务器向导询问域名、网页登录账号密码、联系邮箱。输入 `INSTALL` 后会安装Python服务、Nginx、HTTPS证书及自动续期。
7. 向导自动下载私密配对文件到 `private/pairing.json`。无需手动复制令牌。
8. 按提示把电脑Wi-Fi切换到ESP的 `Gateway-Setup-...` 热点。已配置的ESP正常启动后按BOOT3秒开启热点；密码可从USB115200串口查看。
9. 输入ESP以后应连接的2.4GHz Wi-Fi名称和密码，再输入 `CONNECT`。脚本自动读取设备配置授权码，填入服务器域名、路径、设备ID、令牌和Wi-Fi，并触发保存重启。
10. 电脑切回正常网络，打开新域名登录控制台。验证串口数据后，再到ESP面板开启远程写入。配对默认只读。

SSH步骤可能数次询问密码；配置SSH密钥可减少重复输入。向导不自动修改DNS、不绕过SSH主机校验、不代替烧录或物理接线。

## 只重新配对ESP

服务器部署成功后，不必再运行setup.cmd。连接ESP热点，双击 **connect.cmd** 即可。
配对文件在其他位置时：
```powershell
py -3 deploy\pair.py "D:\安全目录\pairing.json"
```
脚本不使用系统HTTP代理，避免把热点配置密码发给代理。文件含设备令牌，不能发到公开群或提交Git；private目录已加入.gitignore。

## 在服务器手动启动向导

源码已在服务器时：
```bash
cd esp32-universal-gateway
sudo bash deploy/install.sh
```
公开仓库也可直接 `git clone https://github.com/roxy-king/esp32-universal-gateway.git`；不需要把GitHub令牌放到服务器。
部署后下载 `/etc/esp-gateway/pairing.json`，在电脑运行connect.cmd。

## 重跑与故障恢复

- 首次同名目录或服务已存在且不是此向导创建时，会拒绝覆盖。已有手动部署需先人工核查。
- 此向导创建的部署可重跑，保留原账号和令牌。失败后先解决DNS/网络/端口问题，重复运行不会生成另一套令牌。
- 如果8766被其他服务占用，会停止；不会停止或替换其他服务。
- 证书失败：检查DNS解析、80端口、IPv6记录，修复后重跑。向导不会关闭其他站点。
- ESP配对失败：检查热点、固件版本、是否被VPN拦截，运行connect.cmd单独重试。
- 新设备需先使用server/add_device.py独立注册。初始pairing.json只用于最初那台设备；两台ESP必须使用各自独立的设备令牌，不能同时共用一份令牌。
- 服务器已部署不表示ESP已上线；Wi-Fi、NTP、TLS证书和串口链路仍须完成现场验证。

## 代码与发行包区别

Git仓库保存源码、测试、部署文件。Release完整包另外含固件BIN、Windows烧录工具和编译工具，首次使用优先下载Release。
构建缓存、私密配置和令牌不进入Git。此版本不自动上传或更改现有洗衣机网站。
