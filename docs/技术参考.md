# 技术参考

- ESP32-S3开发板与供电/引脚：https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32s3/esp32-s3-devkitc-1/user_guide.html
- Arduino ESP32 Wi-Fi API：https://docs.espressif.com/projects/arduino-esp32/en/latest/api/wifi.html
- 串口API：https://docs.espressif.com/projects/arduino-esp32/en/latest/api/serial.html
- Preferences参数保存：https://docs.espressif.com/projects/arduino-esp32/en/latest/api/preferences.html
- WebSockets库源码与接口：https://github.com/Links2004/arduinoWebSockets
- ArduinoJson：https://arduinojson.org/v7/
- esptool烧录：https://docs.espressif.com/projects/esptool/en/latest/esp32s3/esptool/flashing-firmware.html
- aiohttp服务器：https://docs.aiohttp.org/en/stable/web_quickstart.html
- Nginx WebSocket代理：https://nginx.org/en/docs/http/websocket.html
- Let's Encrypt根证书：https://letsencrypt.org/certificates/

本工程固定使用Arduino ESP32 3.3.2、WebSockets 2.6.1、ArduinoJson 7.4.2，固定设置见build.ps1。文档的latest页面可能比本工程版本更新，升级后需要重新编译和实物验证。
