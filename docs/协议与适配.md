# Gateway v1：项目无关的传输协议

本固件面向 ESP32-S3 N16R8 开发板，UART 3.3V TTL。它不识别洗衣、育苗等业务含义；可以承载这些项目，但不是任意云平台的免适配客户端。

## 连接

ESP32 主动发起 WebSocket，默认 WSS 443 `/gateway/ws`。请求头：
```
Authorization: Bearer <独立设备令牌>
X-Device-Id: <设备ID>
```
服务端 v1.6.0 起按独立令牌唯一匹配注册设备，X-Device-Id 可使用 ESP 自身的 ID，无需与服务器注册键一致。hello/status 中的 device_id 必须与本次请求头一致。重复令牌登记拒绝鉴权，同令牌双连接仍被拒绝。控制台名称/显示 ID 独立持久化，不改变鉴权或已有会话。

所有 WebSocket 消息是完整的 JSON 文本消息，协议版本 `v:1`。不接收分片命令或原生 WS binary。二进制负载放进 hex 字符串。

网关连接后发送 `hello`，此后每5秒发送 `status`。字段包含 `device_id、boot_id、wifi、clock、cloud、mode、remote_write、rx_bytes、tx_bytes、dropped_frames、last_rx_ms、free_heap、uptime_s`。boot_id 每次开机随机改变。

## 远程到单片机

```
{"v":1,"type":"tx","id":"32位随机十六进制ID","boot_id":"当前hello中的boot_id","encoding":"text","data":"PUMP ON","expires_at":1795000005.0}
```

示例 expires_at 仅示意，实际服务器必须填“当前 Unix 秒数 + 5”，不能照抄固定时间。

- 文本模式：`encoding:text`，1至512个UTF-8字节，不含控制字符；自动附加设置中的 CRLF、LF 或无行尾。
- 二进制模式：`encoding:hex`，1至512字节，连续偶数个HEX字符；不自动附加校验码或行尾。
- 必须已校时、boot_id相同、未过期，且有效期不超过10秒、远程写入已开启。
- 网关保留本次运行最近128个命令ID去重，重启后通过变化的boot_id拒绝旧会话命令。它不是永久幂等数据库。
- 每100ms最多发送一条；TX队列不足时拒绝，不自动分批重发。服务端同一设备仅允许一个待确认命令。
- 网关发 `ack`：`ok:true,result:uart_queued_not_executed` 只说明串口写入队列成功。没有保证外设已收到，更不表示水泵已动作。
- 断线/超时/部分写入的结果可能未知；服务端不自动重试。外设应实现自己的命令ID与执行ACK，防止人为重发造成重复动作。

## 单片机到远程

```
{"v":1,"type":"rx","device_id":"seedling-01","boot_id":"...","encoding":"hex","data":"54454d502c32352e35"}
```

上行统一使用HEX保存负载字节；服务器同时展示UTF-8文本。文本行模式遇LF结束，删除结束前一个CR，不发送行尾，忽略空行；单行超过512字节整行丢弃直到下一LF。二进制模式每256字节或空闲5至200ms分包；这不是协议帧解析，长业务帧需要服务端按项目规则重新组帧。

每秒上报最多20个数据块；断网不缓存/不补发UART数据，丢弃计入dropped_frames。适合状态采集与低速控制，不是115200持续满速无损数据记录器。计数是运行期统计，重启归零，长运行32位计数会回绕。

## 智能育苗示例

单片机主动每秒发送一行：
```
{"temp":25.5,"humidity":70,"soil":42,"pump":0,"light":1}
```
单片机自行解析并执行 `PUMP ON`、`PUMP OFF`、`LIGHT ON`、`LIGHT OFF`；执行后主动回报，例如 `ACK,PUMP,ON`。这些名称只是示例，现有洗衣机固件不会理解它们。

育苗的温度阈值、浇水时间上限、断网处理、传感器故障保护必须留在单片机本地。不要把实时安全控制交给网络。

更换项目通常只改：单片机程序、串口参数、服务器对负载的解释与可视化。ESP固件无需跟随业务重编译。

## 边界

- 原洗衣机 `/device/ws` 使用status/snapshot/command等专用协议。本通用版本不能直接替换旧固件并继续用旧网页；须保留旧固件，或另写服务器适配器。
- 本版支持 UART 经 WebSocket/WSS；没有 MQTT、HTTP轮询、蓝牙网关、RS485方向控制、Modbus组帧/CRC、CAN、远程OTA。
- RS485/RS232不能直接接TTL引脚；需对应收发器。5V单片机仍需电平转换。
- 改服务器通常只需面板配置；服务器必须支持本协议与正确证书。任意第三方物联网平台可能需要适配器。

固件 1.3.0 的状态额外提供 `name、baud、rx、tx、format、ending、host、port、path、tls`，不包含密码、令牌或 CA 内容。旧固件缺失这些字段不影响通信。
